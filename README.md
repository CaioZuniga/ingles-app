# Fluent — inglês sob medida

PWA pessoal para aprender inglês: vocabulary (repetição espaçada), grammar, listening, writing e speaking,
personalizado pelo perfil e pelos erros de cada um, com correção pela Claude API (chave do próprio usuário).

- App: https://caiozuniga.github.io/ingles-app/
- Decisões e funcionamento: [PLANO.md](PLANO.md)

```bash
npm install
npm run dev
npm test
```
